Clinical Insight Agent

Review a proposed analysis, run deterministic statistical tools, and keep an inspectable record of the work.

Research prototype. For synthetic or non-sensitive data only. Not for patient care, clinical decisions, PHI, or regulatory submission.

Three ways to work

Review an analysis

Ask a question against a synthetic warehouse, inspect an editable specification, and review the SQL before an inferential run.

Check a result table

Use caveat without an LLM to surface selected statistical concerns and see which checks were skipped.

Explore a trial design

Use assurance for supported Bayesian calculations with explicit assumptions and decision thresholds.

Evidence you can inspect

Tests and public-data examples support software development. They do not establish clinical performance. Model selection uses internal cross-validation; external validation remains necessary. Identifier scanning is not de-identification.
