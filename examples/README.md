# Examples and sources

The key-free examples `synthetic_result.csv`, `synthetic_observations.csv`, `association_spec.json`, and `assurance_design.json` are small constructed examples. Follow the commands in the [root README](../README.md).

The other scripts use copies or transformations of the following public datasets:

- [UCI Heart Disease, Cleveland](https://archive.ics.uci.edu/dataset/45/heart+disease), described in `heart_disease_validation.py`.
- [UCI Heart Failure Clinical Records](https://archive.ics.uci.edu/dataset/519/heart+failure+clinical+records), described in `heart_failure_survival.py`.
- [UCI Breast Cancer Wisconsin Diagnostic](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic), described in `ml_breast_cancer.py`.

These are regression examples on familiar data. Similarity to an earlier result is not independent clinical validation. A reported score may change when the analysis method changes. See [data provenance](../docs/DATA_PROVENANCE.md) and [third-party notices](../THIRD_PARTY_NOTICES.md) for sources, attribution, and known changes.
